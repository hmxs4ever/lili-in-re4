# Lili in RE4

Play as Lili de Rochefort from TEKKEN 8 inside Resident Evil 4 Remake, fighting the Ganados with Tekken-inspired melee.

## What players get
- You start as Lili (replacing Leon) in RE4's world.
- Lili Mode: boosted melee damage and agile movement so her kicks and combos feel stronger against RE4 enemies.
- Detects your own TEKKEN 8 install (companion) and prepares for full model/animation loading from it.
- Solo play.

## Requirements
- Resident Evil 4 (host, primary)
- TEKKEN 8 (companion, for Lili's real content)
- REFramework (installed automatically by Melty)

## First version
Small playable slice: Lili Mode combat tweaks + Tekken folder detection. Full visual model swap (converting Lili's UE5 assets from your Tekken folder into RE Engine meshes) is the next step.
